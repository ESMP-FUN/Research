# Research

Security findings from the ESMP-FUN Security team, published after the affected project has shipped a fix.

## Published findings

None yet.

## How we report

We report every finding privately to the project's maintainers first, with a write-up, a small proof and a suggested fix. We give them 90 days from first contact to ship a fix, longer if they are working on it, and only publish here once a fixed release is out.

## Contact

To report something to us, or to ask about a finding listed here, open a private advisory on this repository or contact the team through the ESMP-FUN organisation.
